# Kotoha Glossary — Ubiquitous Language

本ファイルは Kotoha プロジェクトにおけるドメイン固有語彙を集約する。新規ドメイン用語を specs / plans / コードで導入する際は、本ファイルにも追記して用語の一貫性を保つこと。

## 状態

Phase 0 時点では用語セットが確定していないため、本 glossary は stub である。M3(romaji 変換)以降で用語が固まり次第、順次追加する。

## 凡例(将来の追加時に従う書式)

各用語エントリは以下の形式で記述する:

### 用語名(English name)

- **定義**: 用語の定義(1–2 文で簡潔に)
- **初出**: 最初に定義された spec / plan / コードの参照
- **対応する identifier**: コード上の型名・関数名・モジュール名(該当があれば)
- **備考**: 関連用語、よくある誤用、エイリアスなど
